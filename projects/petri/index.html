Petri

Life-like, from one small table

Each particle has a colour, and the only rule is a table that says how much each colour is drawn to or pushed away from each other colour. Red might chase green while green runs from red.

That is all there is. Nothing here knows what a cell, a worm or a swarm is. Those shapes appear because the attractions don't have to be mutual, so the system never settles: something is always chasing something else.

Up close every particle also pushes its neighbours away, which stops clusters collapsing to a point and gives them a skin.

Press New rules for a fresh random table, or open Rules to edit it yourself and watch the world reorganise.
