Babel

This library holds every page that can be written with 26 letters, a space, a comma and a full stop. Every sentence you will ever say is already on a shelf here. So is the one you're about to type.

How can this be real?

      
The library has 291000 pages, a number with 1,463 digits. There are about 1080 atoms in the observable universe, so nobody could ever store it. Nothing is stored.

      
Instead, every page's address is one enormous number, and a reversible piece of arithmetic turns that number into 1,000 characters. Run it forwards and an address becomes a page. Run it backwards and your text becomes an address. Different addresses always give different pages, so every possible page sits at exactly one place.

      
That is why the link above works: it contains only the address. Open it on another device and the same page is waiting there, because it always was. Turn to the next page and you'll see what nearly all of the library looks like.

      
After Jorge Luis Borges' 1941 story The Library of Babel.
